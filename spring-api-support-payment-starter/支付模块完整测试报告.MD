## 四、发现的问题

### 4.1 独立支付服务路径设计问题

- 当前独立支付服务 `context-path` 为 `/payment/api`
- 支付控制器本身又统一使用 `/api/**`
- 实际对外路径因此变成 `/payment/api/api/**`
- 前端若直接按 `/api/**` 接入，必须额外做一层代理改写

### 4.2 独立支付服务缺失接口

- 商户支付规则管理接口未被映射
- 商户钱包限额管理接口未被映射
- 钱包订单 `simulate-notify` 接口未被映射

这些问题在日志中均表现为：

- `No static resource api/...`

### 4.3 交易流水接口存在运行时异常

- `GET /api/transaction/page` 失败
- 日志报错：
  - `can not find lambda cache for this property [createTime] of entity [TransactionRecord]`

### 4.4 渠道删除接口不可用

- `DELETE /api/channel/{id}` 返回：
  - `Request method 'DELETE' is not supported`
