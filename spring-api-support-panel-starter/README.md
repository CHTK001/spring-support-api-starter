# spring-api-support-panel-starter

统一面板服务 - 数据源管理、DBX嵌入集成、AppImage进程管理

---

## 快速开始

### 1. 添加依赖

```xml
<dependency>
    <groupId>com.chua</groupId>
    <artifactId>spring-api-support-panel-starter</artifactId>
    <version>${project.version}</version>
</dependency>
```

---

## 配置说明

本模块为零配置模块，引入依赖后即可使用。

---
