## ApiKey 认证测试详情

### 13.1 有效 AppKey 鉴权 ✅

**请求**：
```json
{
  "data": "{\"x-oauth-user-code\":\"test-app-key-001\",\"code\":\"sa\"}"
}
```

**响应**：
- `code`: 00000
- `userId`: 1
- `username`: 测试应用
- `roles`: ["SUPER_ADMIN"]
- `ext.appKey`: test-app-key-001

---

### 13.2 无效 AppKey ✅

**请求**：
```json
{
  "data": "{\"x-oauth-user-code\":\"invalid-app-key\",\"code\":\"sa\"}"
}
```

**响应**：
- `code`: C0400S0000
- `msg`: AppKey不存在或无效

---

### 13.3 已禁用 AppKey ✅

**前置条件**：
```sql
UPDATE sys_app_key SET sys_app_key_status = 0 WHERE app_key = 'test-app-key-001';
```

**响应**：
- `code`: C0400S0000
- `msg`: AppKey已禁用

---

### 13.4 缺少 code 参数 ✅

**请求**：
```json
{

}
```

- `code`: C0400S0000
- `msg`: 用户信息不存在: code参数（用户唯一编码）不能为空
