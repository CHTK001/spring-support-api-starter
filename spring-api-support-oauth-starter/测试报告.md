## 已修复 Bug 汇总

| # | 问题 | 修复位置 | 说明 |
|---|------|----------|------|
| 1 | LOGOUT_ALL 只删了发起请求的 token，其他 token 未删除 | `RedisTokenResolver.logout(uid, LogoutType)` | 改为从 token 结构中提取 userIdHash，直接用 `deleteUserAllTokensByHash()` 删除，不依赖 Redis 中 token 是否存在 |
| 2 | refreshToken 刷新后旧 accessToken 未失效 | `RedisTokenResolver.upgradeForRefresh()` | token=null 时从 `oldUserResult.getToken()` 获取旧 AT 并删除 |
| 3 | 临时令牌创建 NPE：`generation(null)` | `TemporaryTokenAuthorization.buildTemporaryUser` + `SimpleTokenGeneration` | buildTemporaryUser 补充 setUid；generation 加 null 保护 |
| 4 | RSocket 响应解密 NPE：`responseSerial` 为 null 时 `Codec.build(key=null)` | `AbstractProtocol.createAuthenticationInformation` | 加 `key != null` 保护，key 为 null 时不解密直接用原始 data |
| 5 | RSocket 响应头未传递：`x-oauth-response-serial` 丢失 | `RsocketOauthProtocol.handleRequest` | 改为共享 `sharedResponse`，把响应头放到 RSocket 响应 metadata 里 |
| 6 | RSocket 鉴权失败返回 500 而非 403：`isVerifyPath` 未匹配 `"oauth"` | `AbstractProtocol.createAuthenticationInformation` | `isVerifyPath` 判断加上 `path.equals("oauth")` |
| 7 | Armeria 协议路径缺少 context-path `/oauth` 前缀 | `application-dev.yml` | 配置 `login-page/logout-page/oauth-url/temporary-token-page/upgrade-page` 加上 `/oauth` 前缀 |
| 8 | Armeria 协议 `upgrade` 路径硬编码，无法配置 | `AuthClientProperties` + `ArmeriaProtocol` | 新增 `upgradePage` 字段，默认 `/upgrade`，`upgradeInformation` 改为使用配置值 |
| 9 | Armeria 协议 refresh 后旧 AT 仍有效（客户端缓存未清除） | `ArmeriaProtocol.upgradeInformation` | REFRESH 升级成功后清除旧 AT 的客户端缓存 |
| 10 | JWT logout NPE：token 为 null 导致 `Cannot invoke "String.length()"` | `LogoutAuthorization.authentication()` | 添加 JWT token 解析逻辑，从 token 中提取 uid（sub 字段），如果 uid 为空则使用 token 本身 |
| 11 | JWT 黑名单功能缺失：logout 后 token 仍然有效 | `RedisTokenResolver.logout()` + `JwtAuthorizationHandler` | 在 logout 方法中调用 TokenBlacklistService.addToBlacklist()，在 JWT 认证时检查黑名单 |
| 12 | sys_app_key 表缺少 sys_app_key_app_id 字段 | `V1.0__init_oauth_complete.sql` | SQL 建表脚本已更新，包含所有必需字段 |
| 13 | AppKey 状态检查逻辑错误：STATUS_ENABLED 常量值为 0 | `SysAppKeyServiceImpl` | 将 STATUS_ENABLED 常量值从 0 更正为 1（1=启用，0=禁用） |

## 12. JWT 鉴权测试

> JWT（JSON Web Token）认证支持 HS256/HS384/HS512（HMAC）和 RS256/RS384/RS512（RSA）等算法。
> 配置：`plugin.oauth.server.jwt.enabled: true`，`algorithm: HS256`，`secret: oauth-server-jwt-secret-key-256bit`。
> JWT token 格式：`header.payload.signature`（三段式），自动识别路由到 `JwtAuthorizationHandler`。

### 前置：生成 JWT Token

**方式 1：使用 PowerShell 生成（HS256）**

```powershell
# 安装 JWT 模块（首次使用）
Install-Module -Name PSJsonWebToken -Force -Scope CurrentUser

# 生成 JWT
$secret = "oauth-server-jwt-secret-key-256bit"
$payload = @{
    sub = "1"  # userId
    username = "sa"
    type = "access"
    iss = "oauth-server"
    exp = [DateTimeOffset]::UtcNow.AddHours(1).ToUnixTimeSeconds()
    iat = [DateTimeOffset]::UtcNow.ToUnixTimeSeconds()
}
$jwt = New-JsonWebToken -Claims $payload -HashAlgorithm SHA256 -SecretKey $secret
Write-Host "JWT Token: $jwt"
```

**方式 2：使用在线工具（jwt.io）**

1. 访问 https://jwt.io/
2. Algorithm 选择 HS256
3. Payload 设置：
```json
{
  "sub": "1",
  "username": "sa",
  "type": "access",
  "iss": "oauth-server",
  "exp": 1735689600,
  "iat": 1735686000
}
```
4. Secret 输入：`oauth-server-jwt-secret-key-256bit`
5. 复制生成的 JWT token

---

### 12.1 有效 JWT Token 鉴权 ✅

**前置**：关闭签名校验（通过 Admin API）

```powershell
# 关闭签名校验
Invoke-RestMethod -Method POST -Uri "http://localhost:19180/oauth/admin/sign-verify?enabled=false"

# 生成 JWT token
$secret = "oauth-server-jwt-secret-key-256bit"
$header = @{alg="HS256";typ="JWT"} | ConvertTo-Json -Compress
$payload = @{sub="1";username="sa";type="access";iss="oauth-server";exp=([DateTimeOffset]::UtcNow.AddHours(1).ToUnixTimeSeconds());iat=([DateTimeOffset]::UtcNow.ToUnixTimeSeconds())} | ConvertTo-Json -Compress
$headerBase64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($header)).TrimEnd('=').Replace('+','-').Replace('/','_')
$payloadBase64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($payload)).TrimEnd('=').Replace('+','-').Replace('/','_')
$signatureInput = "$headerBase64.$payloadBase64"
$hmac = New-Object System.Security.Cryptography.HMACSHA256
$hmac.Key = [Text.Encoding]::UTF8.GetBytes($secret)
$signatureBytes = $hmac.ComputeHash([Text.Encoding]::UTF8.GetBytes($signatureInput))
$signatureBase64 = [Convert]::ToBase64String($signatureBytes).TrimEnd('=').Replace('+','-').Replace('/','_')
$jwt = "$headerBase64.$payloadBase64.$signatureBase64"

$body = @{data=$innerData} | ConvertTo-Json
$result = Invoke-RestMethod -Method POST -Uri "http://localhost:19180/oauth/verify" `

$result | ConvertTo-Json -Depth 3
```
