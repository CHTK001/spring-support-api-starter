## 关键修复详情

### Bug #10: JWT logout NPE
**问题**：JWT 认证流程中，登出接口没有正确处理 JWT token 的提取，导致 NPE

**修复方案**：
- 在 `LogoutAuthorization.java` 中添加 JWT token 解析逻辑
- 从 JWT token 的 payload 中提取 uid（sub 字段）
- 支持 Bearer 前缀的 JWT token
- 添加完整的错误处理和日志记录

**验证结果**：✅ JWT logout 功能正常工作

---

### Bug #11: sys_app_key 表结构问题
**问题**：`sys_app_key` 表缺少必需字段，导致 AppKey 认证功能无法使用

**修复方案**：
1. 更新 SQL 建表脚本 `V1.0__init_oauth_complete.sql`
2. 创建 Java 工具类 `DatabaseUpdateUtil.java` 直接连接数据库执行更新
3. 成功重建表，包含所有必需字段
4. 插入测试数据（test-app-key-001）

**新增字段**：
- `sys_app_key_app_id` - 应用ID
- `app_key` - AppKey字段
- `sys_user_id` - 用户ID
- `sys_app_key_delete` - 删除标记
- `sys_app_key_scope` - 权限范围
- `sys_app_key_grant_types` - 授权类型
- `sys_app_key_redirect_uris` - 回调地址

**验证结果**：✅ AppKey 认证功能正常工作

---

### Bug #12: AppKey 认证状态判断逻辑错误
**问题**：AppKey 认证时状态判断逻辑错误，导致启用的 AppKey 被判断为禁用

**原代码**：
```java
if (dbAppKey.getSysAppKeyStatus() != null && dbAppKey.getSysAppKeyStatus() != 0)
```

**修复后**：
```java
// 检查状态（0=禁用，1=启用）
if (dbAppKey.getSysAppKeyStatus() != null && dbAppKey.getSysAppKeyStatus() == 0)
```

**验证结果**：✅ 状态判断逻辑正确
