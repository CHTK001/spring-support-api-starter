# 企业微信 OAuth2 登录申请指南

## 1. 概述

企业微信扫码登录是腾讯为企业提供的身份验证服务。通过企业微信扫码登录,企业员工可以使用企业微信快速登录您的网站应用,无需注册新账号。

**官方网站**:https://work.weixin.qq.com  
**管理中心**:https://work.weixin.qq.com/wework_admin/frame

**适用场景**:
- 企业内部管理系统登录
- 企业办公应用扫码登录
- 需要获取企业员工信息的 Web 应用
- 企业内部应用的统一身份认证

⚠️ **重要特点**:
- 需要企业注册并创建企业微信
- 支持网页扫码登录
- 可以获取企业员工的详细信息
- 适用于企业内部应用场景

## 2. 前置条件

- [x] 企业营业执照或组织机构代码证
- [x] 企业管理员微信账号
- [x] 企业微信账号(已完成企业认证)
- [x] 已备案的域名
- [x] 应用图标(建议尺寸:120x120 像素)
- [ ] 企业认证(可选,但推荐认证以获得更多功能)

⚠️ **重要提示**:
- 企业微信需要企业信息注册,个人无法申请
- 回调域名必须已完成 ICP 备案
- 需要创建企业自建应用或第三方应用
- 企业认证后可以使用更多高级功能

## 3. 申请流程

### 3.1 注册企业微信

1. 访问 [企业微信官网](https://work.weixin.qq.com)
2. 点击"立即注册"按钮
3. 选择注册方式:
   - 企业注册(推荐)
   - 个体工商户注册
4. 填写企业信息:

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 企业名称 | 营业执照上的企业名称 | XX科技有限公司 | ✓ |
| 行业类型 | 企业所属行业 | 互联网/IT | ✓ |
| 企业规模 | 企业人数规模 | 50-200人 | ✓ |
| 管理员姓名 | 企业管理员真实姓名 | 张三 | ✓ |
| 管理员手机号 | 用于接收验证码 | 13800138000 | ✓ |

5. 使用管理员微信扫码验证
6. 完成注册

### 3.2 企业认证(推荐)

1. 登录企业微信管理后台
2. 进入"我的企业" → "企业信息"
3. 点击"企业认证"
4. 填写认证信息:

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 企业名称 | 营业执照上的企业名称 | XX科技有限公司 | ✓ |
| 统一社会信用代码 | 营业执照上的代码 | 91110000XXXXXXXXXX | ✓ |
| 企业地址 | 营业执照上的地址 | 北京市朝阳区XX路XX号 | ✓ |
| 法人姓名 | 法定代表人姓名 | 李四 | ✓ |
| 法人身份证号 | 法定代表人身份证号 | 110000199001011234 | ✓ |

5. 上传认证材料:
   - 营业执照扫描件
   - 法人身份证正反面
   - 授权书(加盖公章)
6. 等待审核(通常 1-3 个工作日)

### 3.3 创建自建应用

1. 登录企业微信管理后台
2. 进入"应用管理" → "应用" → "自建"
3. 点击"创建应用"按钮
4. 填写应用信息:

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 应用名称 | 显示给员工的应用名称 | 企业管理系统 | ✓ |
| 应用介绍 | 应用的简要描述 | 企业内部管理系统 | ✓ |
| 应用logo | 应用图标(120x120像素) | - | ✓ |
| 可见范围 | 哪些员工可以看到此应用 | 全公司 | ✓ |

5. 创建成功后,在应用详情页面获取:
   - **CorpID**(企业ID,在"我的企业"页面查看)
   - **AgentID**(应用ID)
   - **Secret**(应用密钥)

⚠️ **重要**:
- CorpID 是企业的唯一标识,在"我的企业" → "企业信息"中查看
- AgentID 是应用的唯一标识,在应用详情页面查看
- Secret 只显示一次,请立即保存,不要泄露给他人

### 3.4 配置网页授权及JS-SDK

1. 在应用详情页面,找到"网页授权及JS-SDK"栏目
2. 点击"设置"按钮
3. 配置可信域名:

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 可信域名 | 授权回调域名(不含协议和路径) | example.com | ✓ |

**重要提示**:
- 可信域名只填写域名,不包含 `http://`、`https://` 和路径
- 例如:填写 `example.com`,不要填写 `http://example.com/oauth2/callback`
- 域名必须已完成 ICP 备案
- 最多可配置 3 个可信域名
- 需要下载验证文件并上传到域名根目录进行验证

4. 下载验证文件(WW_verify_xxxxxx.txt)
5. 将验证文件上传到域名根目录(例如:http://example.com/WW_verify_xxxxxx.txt)
6. 点击"确定"完成验证

### 3.5 配置授权回调域

1. 在应用详情页面,找到"企业微信授权登录"栏目
2. 点击"设置"按钮
3. 配置授权回调域:

| 字段 | 说明 | 示例 | 必填 |
|------|------|------|------|
| 授权回调域 | OAuth2 回调域名(不含协议和路径) | example.com | ✓ |

**注意**:授权回调域与可信域名可以相同,也可以不同,但都必须已备案。

## 4. 配置说明

### 4.1 配置参数

| 参数 | 说明 | 必填 |
|------|------|------|
| enabled | 是否启用企业微信登录 | ✓ |
| client-id | 企业微信的 CorpID(企业ID) | ✓ |
| client-secret | 企业微信应用的 Secret(应用密钥) | ✓ |
| agent-id | 企业微信应用的 AgentID(应用ID) | ✓ |
| redirect-uri | 授权回调地址(完整URL) | ✓ |

**参数说明**:
- **CorpID**:企业的唯一标识,在"我的企业" → "企业信息"中查看
- **AgentID**:应用的唯一标识,在应用详情页面查看
- **Secret**:应用密钥,在应用详情页面查看(只显示一次)
- **redirect-uri**:授权回调地址,域名部分必须与企业微信配置的"授权回调域"一致

**回调地址说明**:
- 格式:`http://your-domain/oauth2/callback/wechat-enterprise`
- 域名部分必须与企业微信配置的"授权回调域"一致
- 支持 http 和 https 协议(生产环境建议使用 https)
- 本地测试需要配置 hosts 文件映射域名到 127.0.0.1

## 5. 配置示例

### 5.1 application.yml 配置

```yaml
plugin:
  oauth:
    third-party:
      login:
        wechat-enterprise:
          enabled: true
          client-id: ww1234567890abcdef
          client-secret: 1234567890abcdef1234567890abcdef
          agent-id: "1000002"
          redirect-uri: http://example.com/oauth2/callback/wechat-enterprise
```

**注意**:
- `client-id` 对应企业微信的 CorpID
- `client-secret` 对应应用的 Secret
- `agent-id` 对应应用的 AgentID,建议使用字符串格式(加引号)

### 5.2 本地测试配置

由于企业微信要求授权回调域已备案,本地测试需要特殊配置:

**方法一:配置 hosts 文件**

1. 在企业微信应用中配置授权回调域:`test.example.com`
2. 修改本地 hosts 文件(Windows: `C:\Windows\System32\drivers\etc\hosts`,Mac/Linux: `/etc/hosts`):
   ```
   127.0.0.1 test.example.com
   ```
3. 配置文件使用:
   ```yaml
   redirect-uri: http://test.example.com:19180/oauth2/callback/wechat-enterprise
   ```

**方法二:使用内网穿透工具**

1. 使用 ngrok、frp 等工具将本地服务映射到公网域名
2. 在企业微信应用中配置该公网域名
3. 配置文件使用公网域名

## 6. 测试指南

### 6.1 本地测试

1. 启动您的应用
2. 访问授权接口:
   ```
   GET http://test.example.com:19180/oauth2/authorize/wechat-enterprise
   ```
3. 浏览器会跳转到企业微信授权页面
4. 使用企业微信扫描二维码
5. 在手机上确认授权
6. 授权成功后会自动跳转回您的应用

### 6.2 生产环境测试

1. 确保应用已部署到生产服务器
2. 确保域名已备案且可以正常访问
3. 访问授权接口:
   ```
   GET https://your-domain.com/oauth2/authorize/wechat-enterprise
   ```
4. 扫码授权测试

### 6.3 验证登录

检查应用日志,确认登录成功:

```
INFO  - OAuth2 登录成功: platform=wechat-enterprise, userId=ZhangSan
INFO  - 用户信息: name=张三, department=[1,2], mobile=13800138000
```

## 7. 常见问题

### 7.1 redirect_uri 参数错误

**问题描述**:回调地址域名不匹配

**错误信息**:
```json
{
  "errcode": 50001,
  "errmsg": "redirect_uri域名与后台配置不一致"
}
```

**原因**:配置的回调地址域名与企业微信配置的授权回调域不一致

**解决方案**:
1. 检查配置文件中的 `redirect-uri` 参数
2. 登录企业微信管理后台,检查应用的"授权回调域"配置
3. 确保回调地址的域名部分与授权回调域一致
4. 注意:授权回调域不包含协议和路径,只填写域名

**示例**:
- 授权回调域配置:`example.com`
- 正确的回调地址:`http://example.com/oauth2/callback/wechat-enterprise`
- 错误的回调地址:`http://www.example.com/oauth2/callback/wechat-enterprise`(子域名不匹配)

### 7.2 invalid corpid

**问题描述**:CorpID 参数错误

**错误信息**:
```json
{
  "errcode": 40013,
  "errmsg": "invalid corpid"
}
```

**原因**:CorpID 配置错误或企业已被删除

**解决方案**:
1. 检查配置文件中的 `client-id` 是否正确
2. 登录企业微信管理后台,在"我的企业" → "企业信息"中确认 CorpID
3. 确保复制 CorpID 时没有多余的空格或换行
4. 注意区分企业微信、微信开放平台、微信公众号的 ID

### 7.3 invalid secret

**问题描述**:Secret 参数错误

**错误信息**:
```json
{
  "errcode": 40001,
  "errmsg": "invalid credential, access_token is invalid or not latest"
}
```

**原因**:Secret 配置错误或已重置

**解决方案**:
1. 检查配置文件中的 `client-secret` 是否正确
2. 登录企业微信管理后台,确认应用的 Secret 是否已重置
3. 如果 Secret 已重置,需要使用新的 Secret
4. 确保复制时没有多余的空格或换行

### 7.4 invalid agentid

**问题描述**:AgentID 参数错误

**错误信息**:
```json
{
  "errcode": 40003,
  "errmsg": "invalid agentid"
}
```

**原因**:AgentID 配置错误或应用已被删除

**解决方案**:
1. 检查配置文件中的 `agent-id` 是否正确
2. 登录企业微信管理后台,在应用详情页面确认 AgentID
3. 确保 AgentID 配置为字符串格式(加引号)
4. 确保应用状态正常,未被停用或删除

### 7.5 用户取消授权

**问题描述**:用户在扫码后取消授权

**错误信息**:
```
error=access_denied&error_description=user%20denied
```

**原因**:用户在手机上点击了"取消"按钮

**解决方案**:
- 这是正常的用户行为
- 应用应该友好地提示用户需要授权才能登录
- 可以提供重新授权的链接

### 7.6 未备案域名

**问题描述**:使用未备案域名无法配置

**错误信息**:
```
授权回调域未备案,请先完成域名备案
```

**原因**:企业微信要求授权回调域必须已完成 ICP 备案

**解决方案**:
1. 完成域名的 ICP 备案(通过云服务商申请)
2. 备案通过后,在企业微信管理后台配置该域名
3. 本地测试可以使用 hosts 文件映射已备案的域名

### 7.7 二维码过期

**问题描述**:扫码时提示二维码已过期

**原因**:企业微信登录二维码有效期为 5 分钟

**解决方案**:
- 刷新页面重新获取二维码
- 建议在前端实现二维码自动刷新功能

### 7.8 员工不在可见范围内

**问题描述**:员工扫码后提示无权限

**错误信息**:
```
该应用不在您的可见范围内
```

**原因**:应用的可见范围未包含该员工

**解决方案**:
1. 登录企业微信管理后台
2. 进入应用详情页面
3. 修改"可见范围",添加该员工或部门
4. 保存后重新测试

## 8. 最佳实践

### 8.1 安全建议

1. **保护 Secret**
   - 不要将 Secret 提交到代码仓库
   - 使用环境变量或配置中心管理敏感信息
   - 定期更换 Secret(在企业微信管理后台重置)

2. **使用 HTTPS**
   - 生产环境必须使用 HTTPS 协议
   - 避免在不安全的网络环境下传输用户信息

3. **验证回调来源**
   - 验证 state 参数,防止 CSRF 攻击
   - 验证回调请求的来源域名

4. **Access Token 管理**
   - Access Token 有效期为 2 小时
   - 建议实现 Token 缓存机制
   - 避免频繁调用接口获取 Access Token

5. **权限最小化**
   - 只配置应用必需的可见范围
   - 定期审查应用权限
   - 及时移除离职员工的访问权限

### 8.2 用户体验优化

1. **清晰的授权说明**
   - 在跳转到企业微信授权页面前,告知用户将要进行的操作
   - 说明需要获取哪些信息以及用途

2. **二维码展示优化**
   - 提供清晰的扫码提示
   - 实现二维码自动刷新功能
   - 提供"刷新二维码"按钮

3. **移动端适配**
   - 在移动端浏览器中,自动跳转到企业微信授权页面
   - 避免在移动端显示二维码

4. **错误处理**
   - 提供友好的错误提示
   - 对于常见错误,提供解决建议
   - 提供管理员联系方式

5. **员工信息同步**
   - 定期同步企业微信通讯录
   - 处理员工入职、离职、部门调整等变更
   - 实现增量同步机制

### 8.3 性能优化

1. **缓存用户信息**
   - 合理缓存员工基本信息
   - 减少对企业微信 API 的调用频率
   - 注意用户信息的时效性

2. **异步处理**
   - 用户信息获取采用异步方式
   - 避免阻塞主流程

3. **批量操作**
   - 使用批量接口获取多个员工信息
   - 减少 API 调用次数

4. **监控告警**
   - 监控授权成功率
   - 监控 API 调用失败率
   - 设置异常告警
   - 监控 API 调用频率,避免超限

### 8.4 企业管理建议

1. **应用分类管理**
   - 根据业务场景创建不同的应用
   - 合理设置应用的可见范围
   - 定期清理不再使用的应用

2. **权限管理**
   - 实施最小权限原则
   - 定期审查应用权限
   - 记录权限变更日志

3. **通讯录同步**
   - 保持企业微信通讯录与实际组织架构一致
   - 及时处理员工入职、离职
   - 定期核对部门信息

4. **应用推广**
   - 在企业微信工作台展示应用
   - 提供应用使用指南
   - 收集员工反馈,持续优化
