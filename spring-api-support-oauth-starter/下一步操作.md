### 步骤 3：测试修复结果

#### 3.1 测试 JWT logout（测试 12.4）

```powershell
# 关闭签名校验
Invoke-RestMethod -Method POST -Uri "http://localhost:19180/oauth/admin/sign-verify?enabled=false"

# 生成 JWT token
$secret = "oauth-server-jwt-secret-key-256bit"
$header = @{alg="HS256";typ="JWT"} | ConvertTo-Json -Compress
$payload = @{sub="1";username="sa";type="access";iss="oauth-server";exp=([DateTimeOffset]::UtcNow.AddHours(1).ToUnixTimeSeconds());iat=([DateTimeOffset]::UtcNow.ToUnixTimeSeconds())} | ConvertTo-Json -Compress
$headerBase64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($header)).TrimEnd('=').Replace('+','-').Replace('/','_')
$payloadBase64 = [Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes($payload)).TrimEnd('=').Replace('+','-').Replace('/','_')
$signatureInput = "$headerBase64.$payloadBase64"
$hmac = New-Object System.Security.Cryptography.HMACSHA256
$hmac.Key = [Text.Encoding]::UTF8.GetBytes($secret)
$signatureBytes = $hmac.ComputeHash([Text.Encoding]::UTF8.GetBytes($signatureInput))
$signatureBase64 = [Convert]::ToBase64String($signatureBytes).TrimEnd('=').Replace('+','-').Replace('/','_')
$jwt = "$headerBase64.$payloadBase64.$signatureBase64"

# 测试 JWT 鉴权（应成功）
$innerData = @{"x-oauth-token"=$jwt} | ConvertTo-Json -Compress
$body = @{data=$innerData} | ConvertTo-Json
$result = Invoke-RestMethod -Method POST -Uri "http://localhost:19180/oauth/verify" `
  -ContentType "application/json" -Headers @{"x-oauth-type"="jwt"} -Body $body
Write-Host "鉴权结果: $($result.code)" # 应返回 00000

# 测试 JWT logout（应成功）
$innerData = @{"x-oauth-token"=$jwt} | ConvertTo-Json -Compress
$body = @{data=$innerData} | ConvertTo-Json
$result = Invoke-RestMethod -Method POST -Uri "http://localhost:19180/oauth/logout" `
  -ContentType "application/json" -Headers @{"x-oauth-type"="jwt"} -Body $body
Write-Host "登出结果: $($result.code)" # 应返回 00000

# 再次鉴权（应失败，token 已在黑名单）
$innerData = @{"x-oauth-token"=$jwt} | ConvertTo-Json -Compress
$body = @{data=$innerData} | ConvertTo-Json
try {
    $result = Invoke-RestMethod -Method POST -Uri "http://localhost:19180/oauth/verify" `
      -ContentType "application/json" -Headers @{"x-oauth-type"="jwt"} -Body $body
    Write-Host "再次鉴权结果: $($result.code) - $($result.msg)" # 应返回 C0400S0000, Token 已被撤销
} catch {
    Write-Host "再次鉴权失败（预期）: $_"
}
```

**预期结果**：
- 第一次鉴权：`code=00000` ✅
- 登出：`code=00000` ✅
- 再次鉴权：`code=C0400S0000`, `msg=Token 已被撤销` ✅
