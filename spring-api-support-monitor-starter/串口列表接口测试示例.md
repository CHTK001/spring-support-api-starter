# 串口列表接口测试示例

## 接口说明

新增的获取串口列表接口可以自动检测当前服务器上可用的串口设备，支持Windows、Linux和Mac系统。

**接口地址**: `GET /monitor/api/v1/gen/serial/available-ports`

## 响应格式

```json
{
  "success": true,
  "msg": "操作成功",
  "data": [
    {
      "port": "COM1",
      "name": "通信端口 (COM1)",
      "description": "标准串行端口",
      "type": "serial",
      "available": true,
      "platform": "windows",
      "pnpDeviceId": "ACPI\\PNP0501\\1"
    }
  ]
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| port | String | 串口设备路径 (Windows: COM1, Linux: /dev/ttyUSB0) |
| name | String | 设备友好名称 |
| description | String | 设备描述信息 |
| type | String | 设备类型，固定为 "serial" |
| available | Boolean | 设备是否可用 |
| platform | String | 操作系统平台 (windows/linux/mac) |
| pnpDeviceId | String | PnP设备ID (仅Windows) |

## 不同平台检测方式

### Windows系统
1. **主要方式**: 使用 `wmic` 命令查询 Win32_SerialPort
2. **降级方案**: 使用 `mode` 命令检测 COM1-COM20

### Linux系统
- 扫描 `/dev/` 目录下的设备文件
- 支持的设备类型:
  - `ttyUSB*` - USB转串口设备
  - `ttyACM*` - USB CDC通信设备
  - `ttyS*` - 标准串行端口
  - `ttyAMA*` - ARM UART设备

### Mac系统
- 扫描 `/dev/` 目录下的设备文件
- 支持的设备类型:
  - `cu.usbserial*` - USB串口设备
  - `cu.usbmodem*` - USB调制解调器
  - `tty.usbserial*` - USB串口设备
  - `tty.usbmodem*` - USB调制解调器

## 测试用例

### 1. 使用curl测试

```bash
# 获取串口列表
curl -X GET "http://localhost:19170/monitor/api/v1/gen/serial/available-ports" \
     -H "Content-Type: application/json"
```

### 2. 使用JavaScript测试

```javascript
// 获取并显示串口列表
async function testGetSerialPorts() {
    try {
        const response = await fetch('/monitor/api/v1/gen/serial/available-ports');
        const result = await response.json();
        
        if (result.success) {
            console.log('检测到的串口设备:');
            result.data.forEach((port, index) => {
                console.log(`${index + 1}. ${port.name}`);
                console.log(`   端口: ${port.port}`);
                console.log(`   描述: ${port.description}`);
                console.log(`   平台: ${port.platform}`);
                console.log(`   可用: ${port.available ? '是' : '否'}`);
                console.log('---');
            });
        } else {
            console.error('获取串口列表失败:', result.msg);
        }
    } catch (error) {
        console.error('请求失败:', error);
    }
}

// 调用测试
testGetSerialPorts();
```

### 3. 前端选择器示例

```html
<!DOCTYPE html>
<html>
<head>
    <title>串口选择器</title>
</head>
<body>
    <h3>选择串口设备</h3>
    <select id="serialPortSelect">
        <option value="">请选择串口...</option>
    </select>
    <button onclick="refreshPorts()">刷新列表</button>
    <button onclick="connectToSelectedPort()">连接串口</button>
    
    <div id="portInfo" style="margin-top: 20px;"></div>

    <script>
        // 刷新串口列表
        async function refreshPorts() {
            const select = document.getElementById('serialPortSelect');
            const infoDiv = document.getElementById('portInfo');
            
            try {
                const response = await fetch('/monitor/api/v1/gen/serial/available-ports');
                const result = await response.json();
                
                // 清空现有选项
                select.innerHTML = '<option value="">请选择串口...</option>';
                
                if (result.success && result.data.length > 0) {
                    result.data.forEach(port => {
                        const option = document.createElement('option');
                        option.value = port.port;
                        option.textContent = `${port.name} (${port.port})`;
                        option.dataset.portInfo = JSON.stringify(port);
                        select.appendChild(option);
                    });
                    
                    infoDiv.innerHTML = `<p style="color: green;">检测到 ${result.data.length} 个串口设备</p>`;
                } else {
                    infoDiv.innerHTML = '<p style="color: orange;">未检测到可用的串口设备</p>';
                }
            } catch (error) {
                infoDiv.innerHTML = `<p style="color: red;">获取串口列表失败: ${error.message}</p>`;
            }
        }
        
        // 连接到选中的串口
        function connectToSelectedPort() {
            const select = document.getElementById('serialPortSelect');
            const selectedOption = select.options[select.selectedIndex];
            
            if (!selectedOption.value) {
                alert('请先选择一个串口设备');
                return;
            }
            
            const portInfo = JSON.parse(selectedOption.dataset.portInfo);
            console.log('选中的串口信息:', portInfo);
            
            // 这里可以调用串口连接的相关接口
            // 例如: startSerial(portId)
            alert(`准备连接到串口: ${portInfo.port}`);
        }
        
        // 页面加载时自动刷新串口列表
        window.onload = function() {
            refreshPorts();
        };
    </script>
</body>
</html>
```

## 注意事项

1. **权限要求**: 在Linux系统上可能需要适当的权限才能访问串口设备
2. **设备检测**: 某些虚拟串口或特殊设备可能无法被自动检测到
3. **实时性**: 设备列表反映的是调用接口时的状态，设备的插拔不会实时更新
4. **平台差异**: 不同操作系统的设备命名规则和检测方式有所不同

## 集成建议

1. **定期刷新**: 建议在用户界面提供刷新按钮，允许用户手动更新设备列表
2. **错误处理**: 妥善处理接口调用失败的情况，提供友好的错误提示
3. **设备验证**: 在实际使用串口前，建议先调用测试接口验证设备可用性
4. **缓存策略**: 可以考虑在前端缓存设备列表，避免频繁调用接口
