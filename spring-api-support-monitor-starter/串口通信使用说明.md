# 串口通信功能使用说明

## 功能概述

本模块提供了完整的串口通信功能，支持串口的开启、关闭、数据收发和实时监控。当串口开启时，系统会自动监听串口数据并通过WebSocket实时推送给客户端。

## 主要特性

- ✅ **串口管理**: 支持串口的开启、关闭和状态查询
- ✅ **实时数据推送**: 串口数据通过WebSocket实时推送给客户端
- ✅ **数据发送**: 支持向串口发送数据
- ✅ **跨平台支持**: 支持Windows和Linux/Unix系统
- ✅ **连接监控**: 自动检测串口连接状态
- ✅ **资源管理**: 自动清理串口连接和监听任务

## API接口

### 1. 开启串口
```http
GET /monitor/api/v1/gen/serial/start?id={串口配置ID}
```

### 2. 关闭串口
```http
GET /monitor/api/v1/gen/serial/stop?id={串口配置ID}
```

### 3. 测试串口连接
```http
GET /monitor/api/v1/gen/serial/test?id={串口配置ID}
```

### 4. 向串口发送数据
```http
POST /monitor/api/v1/gen/serial/send?id={串口配置ID}
Content-Type: text/plain

要发送的数据内容
```

### 5. 获取串口状态
```http
GET /monitor/api/v1/gen/serial/status?id={串口配置ID}
```

### 6. 获取可用串口列表
```http
GET /monitor/api/v1/gen/serial/available-ports
```

## WebSocket消息格式

### 串口状态变更消息
**Topic**: `gen/serial/{action}` (action: start/stop/test)

```json
{
  "id": 1,
  "name": "串口名称",
  "port": "COM1",
  "status": 1,
  "action": "start",
  "timestamp": 1640995200000,
  "success": true
}
```

**Topic**: `gen/serial/data`


## 串口配置参数

| 字段 | 类型 | 说明 | 默认值 |
|------|------|------|--------|
| monitorSysGenSerialPort | String | 串口端口名 (如: COM1, /dev/ttyUSB0) | - |
| monitorSysGenSerialBaudRate | Integer | 波特率 | 9600 |
| monitorSysGenSerialDataBits | Integer | 数据位 | 8 |
| monitorSysGenSerialStopBits | Integer | 停止位 | 1 |
| monitorSysGenSerialParity | String | 校验位 (NONE/EVEN/ODD) | NONE |
| monitorSysGenSerialFlowControl | String | 流控制 | - |
| monitorSysGenSerialTimeout | Integer | 超时时间(毫秒) | - |

## 使用示例

### JavaScript客户端示例

```javascript
// 连接WebSocket
const socket = io('/monitor/api');

// 监听串口数据
socket.on('gen/serial/data', (data) => {
    console.log('收到串口数据:', data);
    // 处理接收到的串口数据
    displaySerialData(data.data);
});

// 监听串口状态变更
socket.on('gen/serial/start', (data) => {
    console.log('串口已开启:', data);
});

socket.on('gen/serial/stop', (data) => {
    console.log('串口已关闭:', data);
});

// 监听错误消息
socket.on('gen/serial/error', (data) => {
    console.error('串口操作错误:', data.error);
});

// 获取可用串口列表
function getAvailableSerialPorts() {
    fetch('/monitor/api/v1/gen/serial/available-ports')
        .then(response => response.json())
        .then(data => {
            if (data.success) {
                console.log('可用串口:', data.data);
                // 显示串口列表供用户选择
                displaySerialPorts(data.data);
            } else {
                console.error('获取串口列表失败:', data.msg);
            }
        });
}

// 开启串口
function startSerial(serialId) {
    fetch(`/monitor/api/v1/gen/serial/start?id=${serialId}`)
        .then(response => response.json())
        .then(data => {
            if (data.success) {
                console.log('串口开启成功');
            } else {
                console.error('串口开启失败:', data.msg);
            }
        });
}

// 发送数据到串口
function sendDataToSerial(serialId, data) {
    fetch(`/monitor/api/v1/gen/serial/send?id=${serialId}`, {
        method: 'POST',
        headers: {
            'Content-Type': 'text/plain'
        },
        body: data
    })
    .then(response => response.json())
    .then(result => {
        if (result.success) {
            console.log('数据发送成功');
        } else {
            console.error('数据发送失败:', result.msg);
        }
    });
}
```

## 注意事项

1. **权限要求**: 串口操作可能需要管理员权限，特别是在Linux系统上
2. **端口占用**: 确保串口没有被其他程序占用
3. **系统兼容性**: 
   - Windows: 使用 `mode` 和 `copy` 命令
   - Linux/Unix: 使用 `stty` 和 `cat` 命令
4. **资源清理**: 应用关闭时会自动清理所有串口连接和监听任务
5. **数据格式**: 串口数据以UTF-8编码传输

## 故障排除

### 常见问题

1. **串口打开失败**
   - 检查串口是否存在
   - 确认串口没有被其他程序占用
   - 验证串口参数配置是否正确

2. **数据接收不到**
   - 检查串口连接状态
   - 确认波特率等参数匹配
   - 查看系统日志获取详细错误信息

3. **WebSocket连接问题**
   - 确认WebSocket连接正常
   - 检查Topic订阅是否正确
   - 验证网络连接状态

### 日志查看

系统会记录详细的串口操作日志，可以通过以下方式查看：

```bash
# 查看应用日志
tail -f logs/application.log | grep "串口"
```

## 技术实现

- **串口通信**: 使用系统命令行工具进行串口操作
- **数据监听**: 使用定时任务轮询串口数据
- **消息推送**: 通过Socket.IO实现实时数据推送
- **资源管理**: 使用ConcurrentHashMap管理连接池
- **异常处理**: 完善的异常捕获和错误消息推送机制
