Quick Notes

Recommended flow for validating crawler capability from the Spring module.

1. Preview

Confirm target URL is reachable and cached HTML contains the expected content.

2. Parse

Inspect DOM depth and click nodes to reuse their CSS selector or XPath.

3. Test

Switch between CSS and XPATH until selector result and inspect result both look stable.

4. Persist

Once selectors are stable, move them into the full spider task design page or backend task config.
