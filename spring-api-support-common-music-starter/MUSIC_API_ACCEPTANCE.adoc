= spring-api-support-common-music-starter 接口验收说明

== 接口范围

- `GET /v1/music/sources`
- `GET /v1/music/overview`
- `GET /v1/music/search`
- `GET /v1/music/search/playlists`
- `GET /v1/music/playlist/categories`
- `GET /v1/music/playlist/category`
- `GET /v1/music/playlist/{source}/{playlistId}`
- `GET /v1/music/track/{source}/{trackId}`
- `GET /v1/music/track/{source}/{trackId}/stream`

== source 参数约定

- `source` 为空时:
  - `/overview` 会按优先级尝试可用音源，默认优先 `tx -> kw -> mg -> wy -> kg -> bd -> git -> demo`
  - `/playlist/categories` 和 `/playlist/category` 仍按默认音源处理
- `source=all` 时:
  - 只对 `/search` 和 `/search/playlists` 生效
  - 聚合过程中单个 provider 失败会被隔离，不再拖垮整体结果
  - 结果会按 `source + id` 去重

== 返回字段说明

=== `/v1/music/sources`

- `data[].code`: 音源编码
- `data[].name`: 音源名称
- `data[].description`: 音源说明
- `data[].enabled`: 是否启用

=== `/v1/music/overview`

- `data.sources`: 当前可用音源列表
- `data.defaultSource`: 当前默认音源
- `data.hotKeywords`: 首页热搜词
- `data.featuredPlaylists`: 首页精选歌单

=== `/v1/music/search`

- `source`: 当前查询音源，聚合时固定为 `all`
- `keyword`: 查询关键词
- `page`: 页码，从 `1` 开始
- `pageSize`: 页大小，服务端会限制在 `1..100`
- `total`: 总量，聚合时为各 provider `total` 的求和
- `tracks[]`:
  - `trackId`
  - `source`
  - `title`
  - `artist`
  - `album`
  - `coverUrl`
  - `durationSeconds`

=== `/v1/music/search/playlists`

- 与歌曲搜索类似
- `playlists[]`:
  - `playlistId`
  - `source`
  - `title`
  - `description`
  - `coverUrl`
  - `author`
  - `trackCount`
  - `accentColor`

=== `/v1/music/playlist/{source}/{playlistId}`

- `playlistId`
- `source`
- `title`
- `description`
- `coverUrl`
- `author`
- `trackCount`
- `tracks[]`

=== `/v1/music/track/{source}/{trackId}`

- `trackId`
- `source`
- `title`
- `artist`
- `album`
- `coverUrl`
- `streamUrl`
- `durationSeconds`
- `lyrics`
- `playCount`
- `commentCount`
- `comments[]`

=== `/v1/music/track/{source}/{trackId}/stream`

- 支持透传 `Range`
- 正常情况下返回 `200` 或 `206`
- 上游失败时返回 `502`

== 配置项

- 通用 HTTP 超时:
  - 系统属性 `music.http.connect-timeout-millis`
  - 环境变量 `MUSIC_HTTP_CONNECT_TIMEOUT_MILLIS`
  - 系统属性 `music.http.read-timeout-millis`
  - 环境变量 `MUSIC_HTTP_READ_TIMEOUT_MILLIS`
- GitCode 曲库:
  - 系统属性 `music.git.raw-url`
  - 环境变量 `MUSIC_GIT_RAW_URL`
- 波点歌单白名单:
  - 系统属性 `music.bd.playlist-ids`
  - 环境变量 `MUSIC_BD_PLAYLIST_IDS`

== 已知说明

- `bd` 当前已补齐最小可用搜索能力，搜索结果复用酷我公开搜索并映射为波点音源，保证波点歌曲详情和播放链路可用。
- `bd` 的歌单详情仍依赖 `music.bd.playlist-ids` 或 `MUSIC_BD_PLAYLIST_IDS` 提供歌单 ID 列表。
- 聚合搜索不会暴露 provider 级错误，只会在服务端日志中记录失败源和操作类型。
