## 后端代码变更

### 1. PaymentOrder 实体 @TableField 注解修复
- **文件**: `PaymentOrder.java`
- **变更**: 为所有字段添加 `@TableField` 注解，匹配 PostgreSQL 数据库列名
- **原因**: 实体字段名与数据库列名不一致导致 column "pay_order_id" does not exist

### 2. Merchant 实体列名映射修复
- **变更**: 修复 `pay_merchant_payment_*` 前缀字段映射
- **影响**: 商户列表 API 正常返回

### 3. 双 LIMIT 问题修复
- **文件**: `PaymentAutoConfiguration.java`
- **变更**: 移除重复的 MybatisPlusInterceptor Bean 注册
- **原因**: 多个拦截器导致分页 SQL 追加两个 LIMIT

### 4. PaymentOrderAutoCancelTask 移除
- **文件**: `PaymentOrderAutoCancelTask.java`
- **变更**: 删除自动取消支付订单定时任务
- **原因**: 改为通过 SchedulerJobPlatformAPI 动态管理

### 5. PaymentCipherService AES 加解密
- **文件**: `PaymentCipherService.java`
- **功能**: AES/ECB/PKCS5Padding 对敏感字段（私钥）加解密
- **密钥**: `payment-test-key-20260324`（配置项），回退默认密钥 `PaymentSystem16`
- **兼容性**: 支持 legacy-keys 配置实现新老密钥平滑过渡

### 6. 支付通知控制器
- **文件**: `PaymentNotifyController.java`
- **路由**:
  - `POST /api/notify/alipay/pay/{channelId}` — 支付宝支付异步回调
  - `POST /api/notify/wechat/pay/{channelId}` — 微信支付异步回调
- **响应**: 纯文本 `"success"` / `"failure"`

### 7. 订单同步 API
- **文件**: `OrderController.java`
- **路由**: `POST /api/order/{id}/sync`
- **功能**: 调用支付宝渠道查询订单状态，若已支付则更新本地位为 PAID

## RSA 密钥生成与配置

### 密钥生成
```bash
# 1. 生成 2048 位 RSA 私钥
openssl genrsa -out alipay_test_rsa.pem 2048

# 2. 提取纯净 PKCS8 私钥（无 PEM 头尾，纯 base64）
openssl pkcs8 -topk8 -inform PEM -outform PEM \
  -in alipay_test_rsa.pem -nocrypt | \
  grep -v "BEGIN\|END\|----" | tr -d '\n\r'

# 3. 提取公钥
openssl rsa -in alipay_test_rsa.pem -pubout
```

### 密钥配置流程
1. 生成 RSA 密钥对 → 提取 PKCS8 私钥和公钥
2. 私钥通过 `PaymentCipherService.encrypt()` AES 加密后存入 `pay_merchant_channel` 表
3. 公钥上传至支付宝沙箱开放平台（"自定义密钥"模式 → "公钥模式"）
4. 支付宝平台返回的支付宝公钥存入 `publicKey` 字段

## 支付全链路测试

### 测试流程

```
┌─────────┐    ┌─────────┐    ┌──────────────┐    ┌─────────┐
│ 创建订单  │ → │ 发起支付  │ → │ 支付宝沙箱收银台 │ → │ 买家登录  │
│ PENDING   │    │ PAYING   │    │ 生成 HTML_FORM │    │ tpydme9355│
└─────────┘    └─────────┘    └──────────────┘    └─────────┘
                                                       │
┌─────────┐    ┌──────────────┐    ┌─────────┐         ▼
│ PAID     │ ← │ 同步订单状态   │ ← │ 确认付款  │ ← │ 输入支付密码 │
│ 支付成功  │    │ /api/order/sync│    │ 0.01 元  │    │ 111111     │
└─────────┘    └──────────────┘    └─────────┘    └─────────┘
```

### 步骤详情

#### Step 1: 创建订单
```http
POST /api/order
Content-Type: application/json

{
  "merchantId": 1,
  "channelType": "ALIPAY",
  "channelSubType": "PAY_WEB",
  "orderAmount": 0.01,
  "subject": "测试商品-沙盒支付",
  "body": "支付宝沙盒支付测试订单",
  "returnUrl": "http://127.0.0.1:8085",
  "notifyUrl": "http://127.0.0.1:8085/api/notify/alipay/pay"
}
```
→ 返回 `status: "PENDING"`，订单 ID = 12，订单号 `ORD17782889827228A52E7`

#### Step 2: 发起支付
```http
POST /api/order/12/pay
```
→ 返回 HTML_FORM，包含自动提交表单到支付宝沙箱网关

#### Step 3: 浏览器渲染 → 支付宝收银台
- 导航到支付 HTML 页面
- 表单自动 `POST` 到 `openapi-sandbox.dl.alipaydev.com/gateway.do`
- 跳转至沙箱收银台登录页面

#### Step 4: 买家登录
- 切换为"账密登录"
- 输入账号: `tpydme9355@sandbox.com`
- 点击"下一步"
- 输入支付密码: `111111`

#### Step 5: 确认付款
- 确认金额: **0.01 元**
- 付款方式: **账户余额** (余额: ¥1,000,000.00)
- 无短信校验
- 点击"确认付款"

#### Step 6: 同步订单状态
```http
POST /api/order/12/sync
```
→ 渠道查询返回 PAID，本地订单更新为 **PAID**
