## 🔍 问题分析

### 核心问题
**登录后的页面跳转路径与预期不符**

测试脚本期望登录后跳转到:
- `/home` 或
- `/dashboard`

但实际可能跳转到了其他路径，例如:
- `/welcome`
- `/index`
- `/main`
- 或其他自定义路径

### 解决方案

#### 方案1: 检查实际跳转路径
查看失败测试的截图，确认登录后的实际URL

#### 方案2: 修改测试脚本
更新测试脚本中的URL匹配规则:
```javascript
// 修改前
await page.waitForURL(/\/(home|dashboard)/, { timeout: 10000 });

// 修改后 - 添加更多可能的路径
await page.waitForURL(/\/(home|dashboard|welcome|index|main)/, { timeout: 10000 });

// 或者使用更宽松的匹配
await page.waitForURL((url) => !url.pathname.includes('login'), { timeout: 10000 });
```
